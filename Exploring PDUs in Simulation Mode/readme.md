# Exploring PDUs in Simulation Mode

## Lab Overview

This lab was completed as a self-practice activity in Cisco Packet Tracer to understand how PDUs (Protocol Data Units) move through a network using Simulation Mode. It focuses on observing ICMP traffic and analyzing packet behavior.

## What I Did

* Built and used a small network in Cisco Packet Tracer
* Switched from Realtime Mode to Simulation Mode
* Created a Simple PDU between two devices (Office-Admin and Printer0)
* Observed packet flow using the Capture/Forward tool
* Viewed ICMP request and reply packets in the Event List
* Inspected packet details using OSI Model analysis tools
* Created a Complex PDU to generate periodic ICMP traffic
* Monitored continuous packet transmission in Simulation Mode

## Steps Performed

1. Opened the Packet Tracer workspace and loaded the network.
2. Switched from Realtime Mode to Simulation Mode.
3. Created a Simple PDU from Office-Admin to Printer0.
4. Used Capture/Forward to observe packet movement step by step.
5. Checked ICMP events in the Event List.
6. Inspected packet information using OSI Model and PDU details.
7. Deleted the Simple PDU from the simulation.
8. Created a Complex PDU between Office-Admin and Printer0.
9. Set the PDU to send packets periodically (5-second interval).
10. Started the simulation and observed continuous ICMP traffic.
11. Verified successful packet delivery and responses.
